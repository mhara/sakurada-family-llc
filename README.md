## 沿革・事業内容

代表社員の原誠は、ゲーム会社での開発エンジニア勤務、カンボジアのアグリテックスタートアップ「AGRIBUDDY」の創業エンジニアとしての参画を経て、合同会社サクラダファミリーを設立しました。 

システム開発、データベースアーキテクチャ設計・運用、技術コンサルティングを中心に、ITに関する課題解決を包括的に支援するほか、実店舗におけるサロン事業の運営および現場IT基盤の開発・検証を行っています。

### 主な事業内容

- データベースアーキテクチャ設計・開発
- システム開発・技術コンサルティング
- 独自開発・技術検証（DIYアクアポニックス/IoTシステム開発等）
- 美容サロン事業の運営（担当：LUONG THANH THAO）

## フィロソフィー

### 「囲い込み」から「オープン＆分散」へ。データ主権を各人の手に。

高負荷な開発現場からカンボジアの農業現場まで、泥臭くシステムを構築し続けて辿り着いたのは、ひとつの強い確信です。これからの時代を支えるべきは、特定プラットフォームによる囲い込みではなく、オープンかつ分散型の思想であるということです。

本来、データはそれを作成・所有する個人や組織のものです。システム構造やデータを特定環境に固着させてベンダーロックインを生むのではなく、誰もが自らのデータを自由に扱い、コントロールできる状態を技術で支援したいと考えています。

今後、世界はさらに富や資本の集中を加速させ、中央集権的な仕組みが巨大な構造を形成していきます。他者にデータを委ね、過度に依存するということは、自らの価値の決定権まで他人に握られてしまうことを意味します。人間としての価値や自律性を保ち、「自分たちの価値を自分たちで決める」ためにこそ、データ主権は不可欠です。

特定技術や基盤に過剰依存せず、構造をオープンかつ分散に保つこと。誰もがテクノロジーの自由と持続可能性を手にし、自立した足場を築くこと。それこそが、各々が豊かに生きるための確固たる基盤になると信じています。

合同会社サクラダファミリーは、データベース設計やシステム構築、現場の課題解決において、囲い込みに頼らない開かれた本質的価値を追求し続けます。
