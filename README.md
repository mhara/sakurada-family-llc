## 沿革・事業内容

代表社員の原誠は、カンボジアのアグリテックスタートアップ「AGRIBUDDY」の創業エンジニアとしての参画を経て、合同会社サクラダファミリーを設立しました。 

システム開発、データベースアーキテクチャ設計・運用、技術コンサルティングを中心に、ITに関する課題解決を包括的に支援するほか、実店舗におけるサロン事業の運営および現場IT基盤の開発・検証を行っています。

### 主な事業ドメイン

- データベースアーキテクチャ設計・開発
- システム開発・技術コンサルティング
- 独自開発・技術検証（DIYアクアポニックス/IoTシステム開発等）
- 美容サロン事業の運営（担当：LUONG THANH THAO）

## 代表フィロソフィー / Philosophy

### 「囲い込み」から「オープン＆分散」へ。データ主権を各人の手に。

Webサービスの創業や現場でのIT基盤構築を経て辿り着いたのは、ひとつの強い確信です。  
これからの100年を支えるべきは、特定のプラットフォームによる「囲い込み」ではなく、**「オープンかつ分散型」**の思想であるということです。

本来、データは特定のプラットフォームのものではなく、**それを生み出した各人や各組織のもの**です。  
構造やデータを特定の環境に縛り付け、逃げられない状態にしてロックインするのではなく、誰もが自らのデータを自由に扱える状態を技術でサポートしたいと考えています。

今後、世界はさらに加速度的な集中と変化を迎え、一部の資本や中央集権的な仕組みが巨大な力を握る時代へと向かっていきます。巨大な構造の中で個々の存在感や人間の価値が埋もれ、選択肢を奪われていく世界において、中央への過度な依存から脱却し、個々に光を当てる手段こそが**「オープン＆分散」**です。

特定のものに依存せず、構造をオープンかつ分散に保つこと。それによって誰もが自立したテクノロジーの自由度と持続可能性を手に入れ、一部の支配に抗いながら自身の足で立てる状態をつくること。それこそが、次の100年において誰もが自分らしく豊かに生きるための基盤になると信じています。

合同会社サクラダファミリーは、データベース設計やシステム開発、そして現場の課題解決において、囲い込みに頼らない本質的で開かれた価値を追求し続けます。
